# Vulnerability Explainer

Interprets security vulnerabilities and provides technical explanations, remediation steps, and risk assessments for banking systems.

## Features

- Vulnerability analysis and classification
- CVE lookup and mapping
- Risk assessment and scoring
- Remediation recommendations
- Impact analysis for banking systems
- Compliance mapping
